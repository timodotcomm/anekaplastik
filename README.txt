ANEKA PLASTIK - STATIC MULTIPAGE WEBSITE

Isi:
- index.html          : Home
- about.html          : Tentang Kami
- products.html       : Produk
- portfolio.html      : Portofolio + filter kategori
- contact.html        : Kontak + form email + peta
- styles.css          : seluruh styling responsif
- script.js           : mobile menu, filter portfolio, form email
- assets/             : logo resmi + foto produk dari website lama

Cara menjalankan:
1. Extract ZIP.
2. Buka index.html di browser, atau upload seluruh folder ke hosting.
3. Semua link halaman menggunakan relative path sehingga dapat berjalan sebagai static website.

Catatan:
- Form kontak bersifat static: setelah submit, browser membuka email client dengan penerima aneka_plastik@yahoo.com.
- Peta menggunakan Google Maps embed sehingga memerlukan koneksi internet.
- Header/navigation dibuat merah agar menyatu dengan warna logo resmi.
